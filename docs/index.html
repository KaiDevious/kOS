What it does

One system that handles Windows apps, Apple files, and security work — with its own look.

  • Runs Windows apps

    Wine is built in, so most .exe files just work.

  • Works with Apple files

    Opens iPhone photos (HEIC) and common Mac file types.

  • Security tools built in

    The Kali tool set: nmap, Wireshark, Burp, Ghidra, and more.

  • Sends announcements

    A built-in message of the day and pop-up notifications.

  • Custom look

    Dark and light themes, with a matching wallpaper, boot and login screen.

  • Quality-of-life fixes

    No system beep, reliable networking, and a colored terminal.

How to install

Pick whichever fits you.

Option 1

Install the full kOS

Download the ISO and install it in a virtual machine or on a real computer.

How to install the ISO
Option 2

Add kOS to Kali

On Kali with KDE, add the kOS signing key and repo, then install:

sudo curl -fsSL https://kaidevious.github.io/kOS/apt/kos-archive-keyring.gpg -o /usr/share/keyrings/kos-archive-keyring.gpg
echo 'deb [signed-by=/usr/share/keyrings/kos-archive-keyring.gpg] https://kaidevious.github.io/kOS/apt ./' | sudo tee /etc/apt/sources.list.d/kos.list
sudo apt update
sudo apt install kos-desktop
sudo kos setup
Option 3

Build it yourself

On Kali with KDE, run:

git clone https://github.com/KaiDevious/kOS
cd kOS
sudo bash scripts/kos-setup.sh
Running in VirtualBox? If downloads crawl at a few KB/s on fast internet, it's the virtual network adapter, not your connection. Set Settings → Network → Adapter 1 → Adapter Type to Paravirtualized Network (virtio-net) (keep NAT, Cable Connected on). Downloads jump from KB/s to tens of MB/s. Also worth it: Storage → SATA → Use Host I/O Cache on, and 4+ CPUs.

Installing the kOS ISO

Try kOS in a virtual machine first, or put it on a USB stick to run it on a real computer.

64-bit PC 4 GB RAM or more 30 GB free disk space 16 GB USB stick (USB method)
Path A

In a virtual machine

Safest way to try it. Nothing on your computer changes.

  1. Download kOS.iso and install VirtualBox.
  2. Click New. Type: Linux, Version: Debian (64-bit).
  3. Give it 4 GB+ RAM, 2+ CPUs, and a 30 GB+ disk.
  4. In Settings, set Display to VMSVGA and attach kOS.iso as the optical drive.
Path B

On a real computer

Full speed, using your real graphics card. Back up your files first.

  1. Download kOS.iso and a USB tool: Ventoy or Rufus.
  2. Write the ISO to the USB stick (with Ventoy, just copy the file onto it).
  3. Restart and open the boot menu (usually F12, F11, or Esc).
  4. Pick the USB stick.
Then

Boot and install

  1. At the boot menu, choose Start kOS. It starts on its own after 5 seconds.
  2. You're now in the live desktop. Try it out, nothing is installed yet.
  3. Double-click Install kOS on the desktop.
  4. Pick your language, time zone and keyboard, then choose where to install. Erase disk wipes the whole drive, so only use it on a VM or a computer you're OK wiping.
  5. Create your user account and click Install.
  6. When it's done, shut down, remove the ISO or USB stick, and turn it back on. Welcome to kOS.
Stuck? If the screen is black or garbled after booting, choose Start kOS (safe graphics) from the boot menu. Questions and bugs go on GitHub Issues.

FAQ

Stuff people ask.

Is kOS free?

Yes. The code is open source under GPL-3.0, and the ISO is free to download.

Will installing it wipe my computer?

Only if you choose Erase disk in the installer. To try it safely, use a virtual machine or boot it from a USB stick without installing.

Can I play Roblox on it?

On a real computer, yes, through Sober. In a virtual machine, no: VirtualBox's fake graphics card doesn't support the 3D features Roblox needs. We tried. A lot.

Does it run Windows apps?

Most of them, through Wine. Some apps (especially games with anti-cheat) won't work.

Why is it based on Kali?

Kali comes with a big set of security tools built in. Only use them on devices and networks you own or have permission to test.

What's the message at the top of the terminal?

The MOTD, or message of the day. It's pulled live from GitHub every time you open a terminal, and it's the same one shown at the top of this page.
